PROJECT FILES
- index.html       Home / portfolio dashboard
- resume.html      Resume page with Print / Save PDF button
- biodata.html     Bio-data page with Print / Save PDF button
- style.css        Responsive lavender, white and navy theme
- script.js        jQuery mobile navigation and small UI interactions
- assets/          Profile photograph

RUN LOCALLY
1. Extract this folder.
2. Open the extracted folder in Visual Studio Code.
3. If prompted, trust the folder.
4. Install the Live Server extension (Ritwick Dey), if not already installed.
5. Right-click index.html and choose "Open with Live Server".
6. Open resume.html and biodata.html using the navigation menu.
